ContaLog · Gestão
Conciliação de Inventário
Aprovação das divergências e aplicação de ajustes na base.
Somente o perfil MASTER pode aprovar divergências, liberar rodadas, cancelar inventários e fechar inventários.
Método de Conciliação
1º nível: SKU + LOTE + UNIDADE DE MEDIDA + QUANTIDADE  →  MATCH EXATO
2º nível: SKU + UNIDADE DE MEDIDA + QUANTIDADE  →  ignora o lote para validar a correspondência
3º nível: SKU + QUANTIDADE  →  ignora lote e unidade de medida para validar a correspondência
Sem correspondência: permanece como DIVERGENTE para análise do MASTER.
